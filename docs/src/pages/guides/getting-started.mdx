## Install

```sh
npm install -D @mrmartineau/lil-debugger
```

## Turn it on

Call `lilDebugger()` once, in the browser. It adds its own styles.

```js
import { lilDebugger } from "@mrmartineau/lil-debugger";

if (import.meta.env.DEV) lilDebugger();
```

Load it only in development. This example uses the Vite `import.meta.env.DEV` flag. Change it to your build tool's flag.

## Add debug info

Put any string in a `data-debug` attribute:

```html
<div data-debug="user:42">…</div>
<section data-debug='{"plan":"pro","flags":["beta"]}'>…</section>
```

From a component, pass any value as a string:

```jsx
<Card data-debug={JSON.stringify({ id, status })} />
```

## Use it

| Do this                                       | What happens                                             |
| --------------------------------------------- | -------------------------------------------------------- |
| Hold <kbd>Ctrl</kbd>+<kbd>Shift</kbd>         | Show the debug info. Let go to hide it.                  |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | Keep it on. Press again to turn it off.                  |
| Hover a debug element                         | The panel shows its label and the labels of its parents. |
| <kbd>Alt</kbd>+click                          | Copy the value of the element to the clipboard.          |
| Add `?lil-debug` to the URL                   | Start with it locked on. Good for sharing a link.        |

## What the panel shows

- The value. JSON (JavaScript Object Notation) objects and arrays show on many lines.
- The element: tag, `id`, classes and size, for example `<button#save.btn> 120×40`.
- When you hover nothing: how many debug elements are on the page.

All debug elements get a dashed outline. The innermost hovered one gets a solid outline.

The panel uses `textContent`, so a value can never inject HTML.
